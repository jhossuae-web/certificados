Conexión con GitHub

Con esto, el botón Guardar y publicar sube todo solo al repositorio, sin descargar ni subir archivos a mano.

Crear el token (una sola vez)

  1. Entra a GitHub, abre tu foto arriba a la derecha, Settings, y al final Developer settings.
  2. Personal access tokens, Fine-grained tokens, Generate new token.
  3. En Repository access elige Only select repositories y marca el repositorio de los certificados.
  4. En Permissions, Repository permissions, pon Contents en Read and write.
  5. Genera el token, cópialo y pégalo aquí abajo.

El token se guarda solo en este navegador y nunca se sube al repositorio. Si abres el panel en otra computadora, hay que conectarlo de nuevo.

Nuevo evento

Tres pasos y queda publicado.

1Evento

El nombre del evento no se imprime en el certificado. Sirve para identificarlo en la lista y en la página de validación.

La primera fila debe tener los encabezados. Si no los tiene, se toma la columna 1 como registro y la 2 como nombre.

2Diseño del certificado

Sube tu diseño terminado, con todo el texto ya incluido. Aquí solo ubicas lo que cambia en cada alumno: el nombre, el QR, el código de validación y el texto de verificación. El código, el enlace y el QR se generan solos para cada alumno.

Arrastra un elemento para moverlo. Con el elemento marcado, las flechas del teclado lo mueven de a poco (con Shift, más rápido).
